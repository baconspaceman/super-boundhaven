# Source notes (accessed 2026-09-30)

- Dead Cells (Vasseur, Gamasutra repost via sudonull.com): 3ds Max low-poly model + FBX skeleton; in-house renderer, tiny size, no smoothing; cel shading; keyframe-based, in-betweens added after; "flickering pixels" unsolved, fixed by hand; biggest win = cheap timing revisions. https://sudonull.com/post/14066-Dead-Cells-Using-3D-Pipeline-for-2D-Animation ; index page https://www.gameanim.com/2018/01/31/dead-cells-3d-pipeline-2d-animation/
- Mixamo FAQ (Adobe, last updated 2021-09-14): characters+animations royalty free for personal/commercial/non-profit incl. video games. Raw-file redistribution restriction quoted in Adobe community thread (search result), not on FAQ page itself. https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html
- Blender license page: artwork/renders/.blend are the creator's property. https://www.blender.org/about/license/
- Blender manual ID Mask / Cryptomatte; Shader to RGB; scale-node pixelate tutorial (artisticrender.com).
- DKC: Wikipedia (SGI Challenge workstations, pre-rendered, ACM compression). KI, Vectorman: Wikipedia + search snippets.
