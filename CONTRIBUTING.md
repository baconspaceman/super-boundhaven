# Contributing

Thanks for your interest in Super BoundHaven.

## Code and art contributions: not yet

This is a human-led, long-term project and **pull requests with code, art or design changes are not being accepted yet**. The repository is published for viewing and reference, and licensed as described in [LICENSE-ASSETS.md](LICENSE-ASSETS.md). Unsolicited pull requests will be closed without review. Contribution terms may be added later; any accepted contribution would be licensed under the same terms as the files it changes.

## Feedback is welcome

Please open a GitHub issue for:

- **Bugs** in the prototype, site or docs portal (use the bug template).
- **Feedback** about the design, feel, art direction or documentation (use the feedback template).
- Broken links or typos in the docs.

Please do not include personal information, passwords or tokens in issues. The project uses no tracking or telemetry, and the issue templates ask for none.

## Running the project

See "Run it locally" in the [README](README.md#run-it-locally). Before reporting a bug, `npm test` and `npm run typecheck` should pass on a clean checkout.

## Conduct

Be kind and constructive. Critique ideas, not people.
